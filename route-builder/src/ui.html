Separate steps with commas, spaces or dashes: 5AR-5AR-2IR-B1-W2

    File

    Help

    In Rokitbrick: File > Import the file, place the Zumi straight on the start, green flag, keep it still for 1-2 s. All move scripts are stacked under the main script (scroll down). Upload the main script.

    USB

    Direct upload needs Chrome or Edge on a computer (Web Serial). The .xml download still works.
    Help

    Plug the Zumi in with USB and switch it on. Close Rokitbrick first (only one program can use the port).

    The first time, press Install Route Player: it puts a small program on the Zumi (the same tested move code as the .xml files). After that, Upload route only sends the steps and settings, in about 2 seconds. The Zumi keeps the route when switched off.

    After uploading: unplug the cable, place the Zumi on the start, switch it on. It waits 1.5 s, calibrates the gyro (keep it still), then runs the route.

    Uploading a program from Rokitbrick replaces the Route Player - press Install again afterwards.
